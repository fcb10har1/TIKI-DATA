# P3 rules, decoding and the full workflow

Implemented during the 11 November 2026 integration. These tracking adapters are
separate from `tiki_data.demo` and its synthetic example functions.

`tiki_data.p3.rules:predict` takes a `MatchSpec`, `inputs.features` pointing to a
P1 feature NPZ, and optional settings. It never reads labels or provider ball
status. It confirms a controller after 0.2 seconds with the nearest player within
2.5 metres and at least a 0.75 metre advantage over the opposing nearest player.
Loose, contested and missing observations retain the last controller. Periods
reset all state; frames before the first controller and outside periods are X.

Dead ball is a tracking proxy: observed ball speed below 0.3 m/s and both observed
team mean speeds below 1.2 m/s for two seconds. Once confirmed, this offline rule
backfills that stationary interval. Observed ball motion exits the stoppage.
Missing tracking never establishes a stoppage. This cannot directly observe the
referee, out-of-bounds ball position, or restart legality. The proxy can confuse
slow live play with stoppages and miss stoppages while players move.

`tiki_data.p3.decoder:decode` maximizes summed log emissions minus transition
penalties using exact three-state Viterbi in H,A,D order. Default H/A switch cost
is 6; entering/leaving D costs 3. Emissions are scaled by 25/fps for consistent
physical-time strength at other sampling rates. Zeros are floored at 1e-12.
Periods have independent equal state priors; outside-period frames are X. Ties
are deterministic in H,A,D order. Inputs are never modified.

Optional `rule_weight` in [0,1] geometrically fuses rule emissions with TCN
probabilities before decoding. A positive weight requires declared
`inputs.features`; `settings.rules` holds rules parameters. The default weight
is zero; the initial comparison uses no fusion. No tactical tags are consumed.
Adding tag fusion requires a reviewed alignment contract and validation evidence;
tags must not enter P2 features.

Rules settings are `control_distance_m`, `distance_margin_m`, `control_seconds`,
`stationary_speed_mps`, `team_stationary_speed_mps`, and `stoppage_seconds`.
Decoder settings are `switch_cost`, `dead_cost`, `rule_weight`, and `rules`.
Numeric settings must be finite and valid. The algorithms are deterministic.

## Running everything

With the P2 dependencies installed, this trains and runs the external workflow
from the committed fixed match-level split:

```powershell
python -m tiki_data full --config configs/p2_idsse_v1.json --out runs/full-v1
```

Reuse a previously trained checkpoint with:

```powershell
python -m tiki_data full --config configs/p2_idsse_v1.json --checkpoint artifacts/p2-idsse-20261111/best.pt --out runs/full-v1
```

Use a new output directory. The command compares rules, TCN, and TCN + Viterbi
on identical validation matches, selects mean per-match spellF1 then macroF1,
freezes the winner, evaluates only it on the test match once, and reproduces both
selected-method validation CSVs byte-for-byte. Bootstrap defaults to 1,000 samples
per match. `--skip-test` freezes without evaluating the holdout. Declare costs
with `--switch-cost` and `--dead-cost` before validation. Do not change settings
based on final-test results or create new freezes to repeat final testing.
Preserve the original freeze and its sibling `test_attempts` directory.

When the supplied ATD assets exist under `MTAH_DATA_DIR` or `data`, the command
also builds P1 features, generates the selected-method 199,319-row CSV, and checks
reproduction. Alternatively `--supplied-features` accepts an existing BAR-ATH P1
NPZ. Missing supplied assets produce explicit `external_complete` status with
missing paths; no supplied submission is fabricated. Other errors fail the run.

Weights, inputs, predictions and logs stay in ignored `artifacts/` and `runs/`.
The parent `run.json`, comparison reports, freeze and reproduction reports retain
execution evidence. Checkpoints retain their original training-source fingerprint;
new inference reports fingerprint the complete integration source. Local
reproduction does not establish independent teammate reproduction.
