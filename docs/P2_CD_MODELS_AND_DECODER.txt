C / D possession experiment -- 11 November 2026

C: optional recorded speed
Uses the original 19 P1 features. During training, independently for each window
(including its receptive-field context), recorded ball_speed_mps is zero with
observed=False with probability 0.5. Other features are unchanged. Inference uses
recorded speed when P1 reports it observed, and the existing zero/False convention
otherwise. The TCN learns how to use it; there is no label-driven speed gate.
This differs from A (always observed in IDSSE training) and B (always hidden).
Validation for C checkpoint selection hides recorded speed on every frame.

D: B plus causal Kalman motion
Recorded ball_speed_mps remains zero/False during training and inference. Three
separate features are added: ball_kalman_speed_mps, ball_kalman_velocity_std_mps,
ball_kalman_age_s, each with a separate validity flag. Raw ball-position geometry
is preserved, not filled with predicted positions. Decoder ball_observed still
means an original finite ball position, not a Kalman estimate.
The constant-velocity filter uses only ball x/y in metres and elapsed time. It
resets at period boundaries, rejects large innovations, warms up for at least
three observations, and stops predicting velocity after 0.5 seconds without a
position. It does not use recorded speed, possession labels, ball status, or
future observations. Parameters are fixed in the D config, not fitted on Barca.
D has 22 feature values + 22 flags. Hidden TCN layers are unchanged; its input
projection consequently has slightly more parameters than A/B/C.

Experimental protocol
Train: J03WMX, J03WN1, J03WOH, J03WOY. Validation: J03WPY, J03WQQ.
Test match J03WR9 is not read. Public five-minute labels are never used to fit
normalization, TCN weights, Kalman parameters, or the new decoder weight search.
Train-only normalization, seed 42, width 32, kernel 3, dilations 1/2/4/8/16,
dropout 0.1, core 512, batch 16, AdamW lr 0.001, weight decay 0.0001, clip 1,
60-epoch cap and patience 8. Select mean validation spellF1, then macroF1.
A retains its existing checkpoint selected with speed observed; B/C/D select
with speed hidden. Single-seed validation is not an independent final test.

Primary comparison: recorded speed hidden for all four models on the same
external validation matches and public frames. Fixed decoder temperature 4,
missing_weight 0.5. Also report natural available-speed external validation.
Decoder search: weights 0 / 0.25 / 0.5 / 0.75 / 1, all other settings fixed.
To make missing_weight identifiable, simulate ball-position occlusion in
external validation with 2-second and 10-second blocks independently hidden at
probability 0.4, seed 20261111 plus deterministic match/profile offsets.
Hide all original ball-dependent geometry and recompute D from the occluded
positions, so its filter never sees the hidden data. Choose one shared weight
by mean frame accuracy over B/C/D, both matches, and both gap profiles. Break
ties by distance to 0.5 then the smaller weight. Save the choice before scoring
new C/D public predictions. Natural validation positions are always available,
so changing missing_weight there cannot establish the best value for gaps.
Synthetic gaps are an approximation, not proof of optimal full-match settings.
The public sample is repeatedly inspected development data, not a holdout.

Interpretation
Keep B as the current Barca candidate. Neither new model beat its 90.12% on
the public five minutes. C and D improved clean external validation, so those
gains alone cannot justify replacing B for this tracking provider.
D failed especially on dead ball: recall was 3.20% on Barca, versus a mean
96.88% on external validation. Post-evaluation diagnostics show a strong
source difference: 97.72% of valid IDSSE training dead-ball speed estimates
were below 0.25 m/s, versus 0.81% in the Barca sample. Median estimated speed
on dead-ball frames was approximately 0 m/s in training and 2.74 m/s on Barca.
This suggests that D learned the source-specific relationship between nearly
stationary positions and dead ball; it is an explanation supported by feature
distributions, not a causal proof. D also degraded strongly under artificial
position gaps. No parameters or weights were refitted after this diagnosis.
It does not show that every possible Kalman-based approach will fail.
For the decoder, 0.25 is the better-supported candidate among the five tested
weights: B gap-test accuracy rises from 85.16% (0.5) to 85.65% (0.25), while
Barca five-minute accuracy stays 90.12%. This is not evidence of a measured
full-90-minute gain or a global optimum. Only the public five minutes has
Barca ground truth. More labelled, provider-matched full matches or reserved
longer windows are needed to establish generalization. The existing decoder
config is preserved; the separate selected_decoder.json has missing_weight
listed as fitted on external validation.
